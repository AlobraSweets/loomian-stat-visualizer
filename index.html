Basic rules

  1. Select a + square.
  2. Choose a Loomian matching both its row and column clues.
  3. The same exact Loomian or event skin cannot be used twice.
  4. Event skins and colour variants count as separate answers. Gleaming/Alpha/Gamma variants are not selectable.
  5. Three incorrect selections ends the puzzle.
Difficulty changes clue complexity and how many answers are normally available for each square.
